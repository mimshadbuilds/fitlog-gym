# 🏋️ FitLog — Workout & Fitness Tracking App

A modern fitness workout application built with Next.js that helps users explore exercises, view detailed workout information, build a personal workout plan, and save exercises for later.

## Technologies Used

- **Next.js** — React framework with App Router
- **React** — Component-based UI development
- **TypeScript** — Type-safe development
- **Tailwind CSS v4** — Utility-first styling
- **DaisyUI** — UI components built on Tailwind CSS
- **React Icons** — Icons throughout the application
- **Context API** — Global state management for plans and saved workouts
- **Next/Image** — Optimized image rendering

## Key Features

### 1. 🏋️ Workout Library
Browse a collection of exercises with information such as muscle groups, equipment, duration, calories burned, difficulty, and rating.

### 2. 📋 Detailed Workout Pages
View complete workout details including descriptions, equipment, sets, reps, calories, ratings, and step-by-step instructions.

### 3. 📅 Personal Workout Plan
Add exercises to **Today's Plan** and keep track of the workouts you want to complete.

### 4.  Save Workouts for Later
Save exercises to a dedicated **Saved** list and access them whenever needed.

### 5. 📊 Workout Dashboard & Sorting
Track total exercises, workout duration, and calories burned. Sort your plan and saved workouts by **duration, calories burned, or rating**.
